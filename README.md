# 小鲸鱼·同听（测试版）

安卓应用与独立服务：共享酷狗播放状态，并在用户主动授权后加入普通版双人同听房间进行文字对话。由 Codex 协助开发；遇到问题可以找 Codex 帮忙排查。本项目仍在测试，并非开箱即用的通用安装包。

已在一台 iQOO 手机与一个真实双人房间验证：复制邀请链接、加入、主动开启闲聊、收到回复、从手机退出。新版客户端不提供音乐音频采集；后端保留可选的实验性音频摘要兼容代码，不能因此声称模型直接听见旋律、歌声或歌词。回复格式重试修复已部署，连续聊天稳定性、原生系统分享入口、长时间运行及断线恢复仍需实测。

日常使用：在酷狗开房并复制邀请链接；在应用“同听房间”粘贴并确认加入；等待在线后开启房间闲聊；结束时点击退出并刷新确认。账号凭证、邀请链接、SSH 密钥和私人连接配置请勿提交仓库。陌生人加入时自动暂停；发送结果不确定时不自动重发；新消息堆积满页时暂停以避免漏读。

`android/` 是客户端，`room/` 是房间控制与消息处理，`server/` 是播放状态接收和只读工具，`tests/` 是隔离测试。部分 DSH 适配依赖现有桥接工程，尚需制作通用安装流程和可复现构建说明。未附应用签名密钥、部署脚本、配置、编译工具或 APK。项目代码采用 MIT 许可；第三方授权见 THIRD_PARTY_NOTICES.md。

本地检查：运行 `node --test tests/*.test.mjs` 和 `python -m unittest discover -s tests -p 'test_*.py'`。这些隔离测试不能代替真实房间的稳定性测试。

不要在生产环境直接运行测试或使用未审阅的部署配置。Python 和 Node 测试需在本地隔离环境运行。酷狗的非公开兼容接口可能发生变化；测试结果不保证所有客户端版本可用。
